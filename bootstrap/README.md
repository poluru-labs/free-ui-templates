# Free Web & Mobile Templates (Bootstrap)

**Repository:** [github.com/poluru-labs/subrahmanyam-poluru-free-web-mobile-templates](https://github.com/poluru-labs/subrahmanyam-poluru-free-web-mobile-templates)

Responsive **Bootstrap 5** website and admin templates—**no build step** for static folders. Each template lives under `web/bootstrap/<folder>/` with HTML, assets, and (usually) a local README. Open the in-repo gallery at [`web/bootstrap/index.html`](https://github.com/poluru-labs/subrahmanyam-poluru-free-web-mobile-templates/tree/main/web/bootstrap/index.html) (catalog table; being expanded as new demos land).

Part of the [Free UI Templates](../README.md) catalog. Tailwind templates in the same repository are listed in [../tailwind/README.md](../tailwind/README.md).

## Getting started

```bash
git clone https://github.com/poluru-labs/subrahmanyam-poluru-free-web-mobile-templates.git
cd subrahmanyam-poluru-free-web-mobile-templates
python3 -m http.server 8000
# Gallery: http://localhost:8000/web/bootstrap/
# One template: http://localhost:8000/web/bootstrap/home-cleaning-services/
```

Per-template preview ports and notes (when set) are in each folder’s `README.md`.
